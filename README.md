# 1C-PetProject

Репозиторий проекта: [https://github.com/Uleov/1C-PetProject](https://github.com/Uleov/1C-PetProject)

## Настройка перед запуском

Чтобы все работало корректно, необходимо:

1. Пользователи: Добавить список пользователей: Администратор и Пользователь.
2. Права: Выдать им все права, связанные по роли.
3. Безопасный режим: Отключить безопасный режим.
4. Первый запуск: Обязательно запускаться под Администратором. Только он может подгружать шаблонные данные на сервер, так как подгрузка задевает Регистр Сведений со списком АПИ, который Пользователь не может записывать.

## Архитектура и структура

* Расширение и Конфигурация: Проект выполнен в основной конфигурации и в расширении. В основной конфигурации хранятся только прикладные объекты (для гарантированного сохранения данных). В расширении сосредоточена вся логика, формы, роли и т.п.
* Основное хранение движущихся объектов оставил в документах. Но РС тоже задействовал, поместив туда самые крошечные данные.
* Фотографии: В базе не хранятся, они подгружаются HTTP-запросом динамически при открытии альбома.
* Блокировки: При загрузке шаблонных данных ставится Блокировка Данных на случай одновременного входа двух администраторов.

## Функциональные особенности

* Личная страница пользователя: Работает с помощью Параметров сеанса (берет текущий ID пользователя и подгружает данные). У администратора такой страницы нет.
* Динамическое обновление: Все важные формы обновляются автоматически (раз в 5-7 секунд).
* Отчеты: Один из отчетов выполнен программно в форме для изучения метода создания отчетов извне.

## API Интеграция и примеры запросов

Для авторизации в Postman используйте Basic Auth (Логин: Администратор или Пользователь, без пароля).

### Список эндпоинтов и форматы данных

GET запросы:
* http://localhost/InfoBase1/hs/programm/getpost/2
* http://localhost/InfoBase1/hs/programm/universal/2
* http://localhost/InfoBase1/hs/programm/user/2

POST запросы:
* http://localhost/InfoBase1/hs/programm/addpost/
* http://localhost/InfoBase1/hs/programm/addcomment/

Пример JSON для добавления поста (Айди писать не обязательно, система добавит его сама):
```json
 {
    "Айди": 1666,
    "АйдиПользователя": 1,
    "Заголовок": "id labore ex et quam laborum",
    "Текст": "laudantium enim quasi est quidem magnam voluptate ipsam eos\ntempora quo necessitatibus\ndolor quam autem quasi\nreiciendis et nam sapiente accusantium"
 }
```
Пример JSON для добавления комментария (id писать не обязательно):
```json
{
    "id": 666,
    "postId": 3,
    "userId": 2,
    "body": "laudantium enim quasi est quidem magnam voluptate ipsam eos\ntempora quo necessitatibus\ndolor quam autem quasi\nreiciendis et nam sapiente accusantium"
  }
```
